Version probes are recorded by image ID before restarting the stack, to avoid polluting measured cgroups. Compiler versions for Rust/Go are not inferred from mutable Dockerfile tags.

- Versions, package builds, allocator, linking, server implementation and GC policy can all affect a row. Matching a major version does not isolate the base OS.
- Shared file pages are charged to a cgroup, not divided like PSS; startup order and other workloads can change attribution. Settling does not guarantee cache aging.
- CPU/RAM visibility and limits can alter runtime behavior; lower limits do not guarantee proportionally lower usage. Repeat comparable runs before ranking small gaps.
- The benchmark measures this trivial endpoint while idle after serial traffic. It does not compare throughput, latency, or production concurrency.
